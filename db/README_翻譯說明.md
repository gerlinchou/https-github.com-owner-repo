## 規格（每檔皆通過驗證器 PROBLEMS=0）
- 三鍵各 **20 行**（20/20/20）；只手寫第一人稱，2nd（妳）/ 3rd（{PRIMARY}）由管線自動衍生。
- `{標籤}` 逐字保留，英文時態字尾丟棄；每檔僅用「該檔原文標籤 ∪ {PRIMARY}」，無越界標籤、無殘留英文、括號平衡。
- 摩根＝「我」；生物一律「牠」（雌性烈焰屬靈亦用牠）；第一／二人稱句尾 `♡`，第三人稱句尾 `。`。
- `({PRIMARY})`／`({ACTIVE})` 說話者行三人稱一致、不做人稱轉換。
