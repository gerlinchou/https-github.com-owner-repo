# https-github.com-owner-repo

這是我在 GitHub 上的第一個專案,用來練習 Git 與 Pull Request 的基本流程。

## 內容

目前這個倉庫只包含這份 README,之後會逐步加入程式碼與文件。

## 如何取得

```bash
git clone https://github.com/gerlinchou/https-github.com-owner-repo.git
cd https-github.com-owner-repo
```

## 如何貢獻

1. 從 `main` 建立新分支:`git checkout -b my-change`
2. 修改檔案並提交:`git commit -am "描述你的修改"`
3. 推送分支:`git push -u origin my-change`
4. 在 GitHub 上開啟 Pull Request,合併到 `main`
